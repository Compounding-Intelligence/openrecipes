Notes for DeepSeek-V4-Flash

  • Weights: a BF16 cast of sgl-project/DeepSeek-V4-Flash-FP8 (an FP8 repackaging of deepseek-ai/DeepSeek-V4-Flash), converted to Megatron torch_dist with miles v0.1.0.
  • MODEL_ARGS come from miles' miles/utils/external_utils/model_args_utils.py deepseek-v4-flash; run the command from a miles checkout.
  • Build the rows with --loss-mask-type deepseek_v4 --trust-remote-code from a checkout of deepseek-ai/DeepSeek-V4-Flash that carries encoding/ (data/README.md).
  • The router gate and the score-correction bias stay frozen (--moe-router-freeze-gate --freeze-e-score-correction-bias), as miles' DeepSeek-V4 training requires.
  • Keep the kernel caches ($KERNEL_CACHE) on shared storage so pipeline stages reuse each other's TileLang and Triton compiles; with per-node caches, step 0 compiles stage by stage.

CommandHow to run
export CUDA_DEVICE_MAX_CONNECTIONS=1
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
export TILELANG_CACHE_DIR="$KERNEL_CACHE/tilelang"
export TRITON_CACHE_DIR="$KERNEL_CACHE/triton"
export TORCHINDUCTOR_CACHE_DIR="$KERNEL_CACHE/inductor"
export FI_PROVIDER=efa
export FI_EFA_USE_DEVICE_RDMA=1

MODEL_ARGS_LINE="$(python3 miles/utils/external_utils/model_args_utils.py deepseek-v4-flash)"
read -ra MODEL_ARGS <<< "$MODEL_ARGS_LINE"
python3 train.py \
  --actor-num-nodes 8 \
  --actor-num-gpus-per-node 8 \
  --num-gpus-per-node 8 \
  "${MODEL_ARGS[@]}" \
  --hf-checkpoint "$HF_CKPT" \
  --ref-load "$TORCH_DIST" \
  --model-name deepseekv4 \
  --qkv-format bshd \
  --moe-router-freeze-gate \
  --freeze-e-score-correction-bias \
  --rollout-function-path pretokenized_sft_rollout.generate_rollout \
  --prompt-data "$SFT_DATA" \
  --input-key messages \
  --metadata-key metadata \
  --num-rollout 20 \
  --rollout-batch-size 128 \
  --global-batch-size 128 \
  --loss-type sft_loss \
  --calculate-per-token-loss \
  --disable-compute-advantages-and-returns \
  --debug-train-only \
  --tensor-model-parallel-size 2 \
  --sequence-parallel \
  --pipeline-model-parallel-size 4 \
  --decoder-first-pipeline-num-layers 11 \
  --decoder-last-pipeline-num-layers 10 \
  --context-parallel-size 1 \
  --expert-model-parallel-size 8 \
  --expert-tensor-parallel-size 1 \
  --recompute-granularity full \
  --recompute-method uniform \
  --recompute-num-layers 1 \
  --micro-batch-size 1 \
  --optimizer adam --lr 1e-5 --lr-decay-style cosine --min-lr 1e-6 \
  --lr-warmup-fraction 0.1 --weight-decay 0.1 --adam-beta1 0.9 --adam-beta2 0.98 \
  --use-distributed-optimizer \
  --attention-dropout 0.0 --hidden-dropout 0.0 \
  --accumulate-allreduce-grads-in-fp32 --attention-softmax-in-fp32 \
  --distributed-timeout-minutes 30
