Notes for Nemotron-3-Super-120B-A12B

  • Weights: the BF16 checkpoint nvidia/NVIDIA-Nemotron-3-Super-120B-A12B-BF16 (revision 2dc98e2a), with no conversion: miles loads it through Megatron-Bridge (--megatron-to-hf-mode bridge), so --hf-checkpoint and --ref-load are both the checkpoint directory.
  • MODEL_ARGS come from miles' scripts/models/nemotron-3-super-120b-a12b.py at commit 78527b91, printed by miles/utils/external_utils/model_args_utils.py nemotron-3-super-120b-a12b; run the command from a miles checkout at that commit.
  • miles' Nemotron-H bridge shim (miles_plugins/megatron_bridge/nemotron_h.py) leaves out the checkpoint's multi-token prediction layer unless MILES_NEMOTRONH_KEEP_MTP is set, so the recipes train without it.
  • It trains on rows built from its own tokenizer with --loss-mask-type qwen3_5; they are byte-identical to the Nemotron-3-Nano rows (data/README.md).

#1attune-tp4-pp2-ep8-mt16k1,045.2 tokens/s/GPUTP4 PP2 EP8 DP2max 16,384 tokens/GPU, selective MoE recompute, CPU optimizer offload 0.55
  • Starting point: miles' Nemotron-3-Super launcher, scripts/run_nemotron_3_super_120b_a12b.py at miles 0.1.0 (model page https://miles.radixark.com/docs/models/nemotron/nemotron-3-super). miles publishes it as a GRPO recipe with no tokens/s figure. Ported to this workload with its 16-GPU layout (TP 4 with sequence parallel, PP 2, EP 8, full recompute, max 1,024 tokens/GPU, Adam on the CPU) on 16 H200, it measured 688.3 tokens/s/GPU; ATTUNE tuned it to 1,045.2 (+52%).
  • The reference recipe's full recompute has no effect on this model: Megatron's MambaStack (megatron/core/ssm/mamba_block.py at commit 37f91617) has no recompute path. Selective recompute of the MoE layers frees the memory that holds 45% of the optimizer state on the GPU (--optimizer-offload-fraction 0.55).
  • 0.55 is the lowest offload fraction that fits at two rows per microbatch: a tuning run at 0.45 ran out of memory at step 2, and one at 0.55 with three rows per microbatch at step 0. Check the memory before lowering the fraction or raising --max-tokens-per-gpu.
