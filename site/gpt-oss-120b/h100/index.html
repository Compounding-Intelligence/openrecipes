Notes for gpt-oss-120b

  • Weights: openai/gpt-oss-120b (revision b5c939de) with its MXFP4 experts dequantized to BF16 by the training image's tools/preprocess_gpt_oss.py, converted to Megatron torch_dist with slime's tools/convert_hf_to_torch_dist.py.
  • MODEL_ARGS are the architecture written out in the command, with --spec attune_gpt_oss_yarn get_gpt_oss_yarn_spec. The spec in patches/attune_gpt_oss_yarn.py sets YaRN RoPE from the checkpoint's config.json, which slime's stock gpt-oss script does not build.
  • It trains on the gpt-oss rows; the tokenizer and chat template are byte-identical to gpt-oss-20b's.

MODEL_ARGS=(
  --spec attune_gpt_oss_yarn get_gpt_oss_yarn_spec
  --num-layers 36 --hidden-size 2880 --ffn-hidden-size 2880
  --num-attention-heads 64 --group-query-attention --num-query-groups 8 --kv-channels 64
  --padded-vocab-size 201088 --tokenizer-type HuggingFaceTokenizer
  --normalization RMSNorm --norm-epsilon 1e-5 --untie-embeddings-and-output-weights
  --position-embedding-type rope --rotary-percent 1.0 --rotary-base 150000 --no-rope-fusion
  --num-experts 128 --moe-ffn-hidden-size 2880 --moe-router-topk 4 --moe-router-score-function softmax
  --moe-grouped-gemm --quick-geglu --glu-linear-offset 1.0 --activation-func-clamp-value 7.0
  --softmax-type learnable --window-attn-skip-freq 2 --window-size 127,0
)

python3 -m <slime entry module> --async \
  --actor-num-nodes 8 --actor-num-gpus-per-node 8 \
  ${MODEL_ARGS[@]} \
  --seq-length 8192 \
  --hf-checkpoint $HF_CKPT --ref-load $TORCH_DIST \
  --rollout-function-path pretokenized_sft_rollout.generate_rollout \
  --prompt-data $SFT_DATA --input-key messages --metadata-key metadata \
  --num-rollout 20 --rollout-batch-size 128 --global-batch-size 128 \
  --loss-type sft_loss --calculate-per-token-loss --disable-compute-advantages-and-returns --debug-train-only \
  --tensor-model-parallel-size 1 --pipeline-model-parallel-size 8 \
  --decoder-first-pipeline-num-layers 3 --decoder-last-pipeline-num-layers 3 \
  --context-parallel-size 1 --expert-model-parallel-size 8 --expert-tensor-parallel-size 1 \
  --use-dynamic-batch-size --max-tokens-per-gpu 8192 \
  --recompute-granularity full --recompute-method uniform --recompute-num-layers 1 \
  --moe-router-load-balancing-type none --moe-aux-loss-coeff 0.0 \
  --moe-token-dispatcher-type alltoall --moe-permute-fusion --moe-router-fusion --no-bias-dropout-fusion \
  --cross-entropy-loss-fusion --cross-entropy-fusion-impl te \
  --manual-gc --manual-gc-interval 100 \
  --attention-dropout 0.0 --hidden-dropout 0.0 \
  --optimizer adam --lr 5e-6 --min-lr 5e-7 --lr-decay-style cosine --lr-warmup-iters 10 --lr-decay-iters 50 \
  --adam-beta1 0.9 --adam-beta2 0.95 --adam-eps 1e-8 --clip-grad 1.0 \
  --weight-decay 0.033 --weight-decay-incr-style constant \
  --use-distributed-optimizer --grad-reduce-in-bf16 --no-check-for-nan-in-loss-and-grad --seed 1234
